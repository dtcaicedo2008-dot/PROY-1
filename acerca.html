Proyecto Productivo - Programación de Software

📌 Sobre el proyecto

GameZone SENA es una plataforma web interactiva creada para brindar una experiencia de entretenimiento mediante diferentes juegos digitales. El proyecto busca aplicar los conocimientos adquiridos en programación, diseño web y desarrollo de aplicaciones.

❗ Planteamiento del problema

Actualmente existen diferentes plataformas de entretenimiento, pero muchas no integran actividades que permitan desarrollar habilidades cognitivas como la memoria, concentración y lógica. Por esta razón se creó GameZone SENA, una aplicación que reúne varios juegos interactivos en un solo lugar.

🎯 Objetivo general

Desarrollar una plataforma web de juegos interactivos utilizando HTML, CSS y JavaScript, permitiendo al usuario disfrutar de diferentes actividades digitales.

📋 Objetivos específicos

  • Diseñar una interfaz amigable y fácil de utilizar.
  • Crear juegos funcionales mediante programación.
  • Implementar navegación entre diferentes páginas.
  • Aplicar conocimientos adquiridos durante la formación.

💻 Tecnologías utilizadas

HTML CSS JavaScript Visual Studio Code
