🎯 Sobre nuestro proyecto

GameZone es una plataforma web de juegos interactivos desarrollada como proyecto productivo del programa de Programación de Software.

Objetivo: crear una plataforma entretenida, interactiva y fácil de utilizar, aplicando los conocimientos adquiridos durante nuestra formación en programación de software.

💻 Tecnologías utilizadas

Para desarrollar GameZone SENA utilizamos diferentes herramientas y lenguajes de programación.

🌐

HTML

Utilizamos HTML para crear la estructura de las páginas, formularios, botones, textos y elementos de nuestra aplicación.

🎨

CSS

Utilizamos CSS para diseñar la interfaz, agregar colores, tamaños, posiciones, animaciones y diferentes estilos.

⚡

JavaScript

Utilizamos JavaScript para agregar lógica, interactividad, funciones, condiciones y el funcionamiento de los juegos.

🧠 Habilidades desarrolladas

Durante la creación de GameZone SENA desarrollamos habilidades técnicas y personales que nos ayudaron a construir nuestro proyecto.

💻

Programación

Aprendimos a utilizar HTML, CSS y JavaScript para crear páginas web y juegos interactivos.

🎨

Diseño web

Aprendimos a crear interfaces atractivas utilizando colores, botones, animaciones y diferentes estilos.

🧠

Lógica de programación

Utilizamos variables, funciones, condiciones y eventos para crear las reglas de los juegos.

🔧

Resolución de problemas

Aprendimos a identificar errores en el código y buscar soluciones para mejorar el proyecto.

🤝

Trabajo en equipo

Organizamos las actividades y trabajamos conjuntamente para desarrollar el proyecto.

✨

Creatividad

Diseñamos la apariencia de los juegos y buscamos ideas para ofrecer una experiencia atractiva.

🖥️

Visual Studio Code

Aprendimos a crear, organizar, editar y probar nuestros archivos utilizando Visual Studio Code.

🎮

Desarrollo de juegos

Aplicamos nuestros conocimientos para desarrollar los cinco juegos de GameZone SENA.

📚 ¿Qué aprendimos?

Con este proyecto aprendimos que desarrollar una aplicación no consiste solamente en escribir código. También es necesario planificar, diseñar, trabajar en equipo, probar cada función, solucionar errores y pensar en la experiencia del usuario.

💡 Nuestro aprendizaje: logramos aplicar nuestros conocimientos de programación en un proyecto práctico, fortaleciendo nuestras habilidades técnicas, nuestra creatividad y nuestra capacidad para trabajar en equipo.
