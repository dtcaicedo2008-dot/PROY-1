Acerca de GameZone

Bienvenidos a GameZone, una plataforma web interactiva creada para ofrecer una experiencia divertida, educativa y entretenida a través de diferentes juegos.

Nuestro proyecto fue desarrollado aplicando conocimientos de HTML, CSS y JavaScript, utilizando Visual Studio Code como herramienta de desarrollo.

🎯 ¿Qué es GameZone?

GameZone SENA es un aplicativo web diseñado como proyecto de formación del programa de Programación de Software.

La plataforma permite que los usuarios ingresen mediante un sistema de Login y posteriormente accedan a un Dashboard donde pueden seleccionar diferentes juegos.

Nuestro objetivo es combinar la programación con el entretenimiento, creando una página sencilla, llamativa y fácil de utilizar.

🚀 Objetivo del proyecto

Desarrollar una plataforma web interactiva que permita a los usuarios disfrutar diferentes juegos mientras se aplican conceptos fundamentales del desarrollo web.

🎮 Juegos disponibles

GameZone cuenta con cinco juegos diferentes:

🎯

El Ahorcado

Adivina la palabra teniendo en cuenta su categoría y evitando cometer demasiados errores.

✊

Piedra, Papel o Tijera

El jugador se enfrenta contra la computadora y debe elegir una de las tres opciones.

⭕

Tres en Raya

Juego para formar una línea de tres símbolos en un tablero de 3 × 3.

🧠

Trivia de Preguntas

Responde diferentes preguntas y consigue la mayor cantidad de puntos posible.

🃏

Juego de Memoria

Encuentra todas las parejas de cartas utilizando tu memoria.
